# Artists

## Overview

Manage artists

## Contexts

| Context | Base Path         | Authentication | Description                                    |
| ------- | ----------------- | -------------- | ---------------------------------------------- |
| `me`    | `/v1/me/artists/` | Required       | Artists associated with the authenticated user |

## Endpoints

#### List

`GET {base}`

#### Retrieve

`GET {base}{id}/`

#### Delete

`DELETE {base}{id}/`
