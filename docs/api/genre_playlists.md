# Genre Playlists

## Overview

Manage playlists based on genres.

## Contexts

| Context | Base Path                 | Authentication | Description                                     |
| ------- | ------------------------- | -------------- | ----------------------------------------------- |
| `me`    | `/v1/me/genre-playlists/` | Required       | Genre playlists owned by the authenticated user |

## Endpoints

#### List

`GET {base}`

#### Retrieve

`GET {base}{id}/`
