# Manual Playlists

## Overview

Manage manual playlists

## Contexts

| Context | Base Path                  | Authentication | Description                                      |
| ------- | -------------------------- | -------------- | ------------------------------------------------ |
| `me`    | `/v1/me/manual-playlists/` | Required       | Manual playlists owned by the authenticated user |

## Endpoints

#### List

`GET {base}`

#### Retrieve

`GET {base}{id}/`

#### Create

`POST {base}`

#### Update

`PUT {base}{id}/`
