# Plays

## Overview

Manage play history

## Contexts

| Context | Base Path       | Authentication | Description                             |
| ------- | --------------- | -------------- | --------------------------------------- |
| `me`    | `/v1/me/plays/` | Required       | Play history for the authenticated user |

## Endpoints

#### List

`GET {base}`

#### Retrieve

`GET {base}{id}/`

#### Create

`POST {base}`
